# Contributing Guidelines

Este é um curso educacional. Contribuições são bem-vindas!

## Como Contribuir

1. **Bug Reports:** Abra uma issue descrevendo o problema
2. **Sugestões:** Discuta em GitHub Discussions
3. **Melhorias:** Faça um pull request

## Pull Request Process

1. Fork o repositório
2. Crie uma branch (`git checkout -b feature/improvement`)
3. Commit suas mudanças (`git commit -am 'Add improvement'`)
4. Push para a branch (`git push origin feature/improvement`)
5. Abra um Pull Request

## Código Standards

- Python 3.11+
- Use black para formatação
- Use type hints
- Adicione docstrings
- Escreva testes
